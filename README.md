# ⚡ Reeshika Electronics - EV Chargers

Premium EV Charger website for **2 Wheeler & 3 Wheeler** electric vehicles.

## 🌟 Features

- 🎨 Modern Blue + Green glassmorphism UI
- 📱 Fully responsive (mobile + desktop)
- ⚡ 18+ Charger models (48V, 60V, 72V)
- 📦 Product catalog with tabs
- 🛒 Order placement form
- 🏢 3 Branches (Nellore, Bengaluru, New Delhi)
- 🔐 Admin panel with lead management
- 💬 WhatsApp & Call integration
- 🚚 Pan-India delivery info

## 🛠️ Tech Stack

- **Backend:** Flask (Python)
- **Database:** SQLite + SQLAlchemy
- **Auth:** Flask-Login
- **Frontend:** HTML5, CSS3, JavaScript
- **Icons:** Font Awesome
